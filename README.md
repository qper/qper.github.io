# Физика в JavaScript

14 законченных русскоязычных уроков с отдельными статическими адресами, Canvas-сценами, численными упражнениями и итоговой игрой. Обычные ES-модули; сторонних зависимостей, сервера приложения, внешних API, секретов и аналитики нет. Прогресс и черновики хранятся в localStorage с обработкой недоступного хранилища.

**Состояние исходной папки:** при начале работы здесь не было Git-репозитория, remote, основного сайта, CNAME или Pages workflow. Поэтому интеграция с настоящим существующим сайтом не проверена; его конфигурация не менялась. Этот проект нужно добавить в его checkout, а не публиковать как замену корня домена.

## Запуск

Нужны Node.js 22+ и Python 3. Дополнительная установка через npm не требуется.

```sh
npm run build
npm start
```

Открыть http://localhost:8000/js/. Например, прямой адрес:
http://localhost:8000/js/lessons/12-magnet/.
Не открывать HTML через file://: браузер может блокировать ES-модули.

```sh
npm test
```

Сборка создаёт `dist/js/index.html`, `dist/js/assets/*` и 14 файлов `dist/js/lessons/<slug>/index.html`. Все локальные URL относительные. Перезагрузка длинного адреса работает без SPA fallback. Сборка перезаписывает **только подкаталог js/**; перед первым запуском убедитесь, что существующий `/js/` не содержит другой проект.

## Структура

- `course/assets/lessons.js` — цели, идеи, упражнения, подсказки, решения, ограничения.
- `course/assets/model.js` — чистая численная модель: шаг времени, силы, ограничения, коллизии, игровой счёт.
- `course/assets/render.js` — отрисовка модели Canvas 2D.
- `course/assets/scene.js` — Pointer Events, параметры, пауза, шаг, клавиатура, цикл rAF.
- `course/assets/exercises.js` — ограниченный арифметический парсер и проверка трёх случаев.
- `course/assets/app.js` — локальный прогресс, черновики, редактор и численные эксперименты.
- `scripts/build.mjs` — статические страницы, навигация и содержимое без клиентского роутера.
- `tests/course.test.mjs` — 37 проверок численного поведения, упражнений и статических адресов.

Canvas 2D выбран для небольших сцен с десятком движущихся объектов и общим способом рисования. HTML используется для текста, редактора, подсказок и управления: они остаются доступными для клавиатуры и экранного диктора. Сам Canvas имеет текстовое описание и численный статус; он не является полной невизуальной заменой геометрии сцены.

## Добавление в существующий GitHub Pages

Предпочтительно **сохранить существующий workflow**. В его сборку основного сайта добавьте перед upload-pages-artifact:

```sh
PAGES_DIR=_site node scripts/build.mjs
```

Здесь `_site` — уже готовый корневой каталог основного сайта; замените на свой (`dist`, `public`, `out` и т. д.). Сборщик добавит `_site/js/` и сохранит остальные файлы, включая корневой index.html и CNAME. Загружать нужно **весь корневой каталог**, а не только `js/`. GitHub Pages разворачивает единый артефакт сайта; отдельная публикация папки курса может заменить основной сайт.

Если workflow действительно отсутствует, приложен `.github/workflows/pages.yml`: только ручной `workflow_dispatch`, без автопубликации при push. Он ожидает готовый основной сайт в `public/` (включая существующий CNAME, если он используется). Без `public/index.html` публикация намеренно завершается ошибкой, чтобы не заменить основной сайт одним курсом. Альтернатива — заменить шаг копирования `public/` существующей сборкой основного сайта.

После интеграции: Settings → Pages → Source: GitHub Actions, затем вручную Run workflow. Cloudflare, DNS и custom domain изменять не нужно. В этой работе ничего не отправлено в remote и не опубликовано; выполнение workflow будет отдельным действием владельца.

При branch-based Pages можно скопировать содержимое `dist/js/` в `js/` уже публикуемого каталога основной страницы. Корневой CNAME сохраняется.

## Проверки и границы готовности

Автоматически проверены: решения/ошибочные ответы всех 14 упражнений; отсутствие исполняемого синтаксиса в парсере; 20 секунд симуляции каждой сцены при обычных и крайних параметрах; гравитация, сохранение импульса при упругом ударе равных масс, длины жёстких связей, выключатель цепи, создание связей и попадание в полной игровой сцене. Ссылки, ресурсы и прямые пути всех 15 страниц проверяются по итоговой сборке. Отдельный тест подтверждает сохранение корневых файлов и CNAME.

Локальный сервер запущен командой `npm start`: главная, четыре урока (включая длинный адрес магнитного урока) и все семь ресурсов получили HTTP 200; JS выдаётся с MIME text/javascript. Все ES-модули также прошли `node --check`.

Полная визуальная проверка в браузере, мобильное взаимодействие и проверка консоли в этой среде не выполнены: предусмотренный инструмент браузерного QA недоступен. Перед публикацией выполните чек-лист `QA.md`. Адаптивные стили, высокий DPR, Pointer Events и размеры контролов реализованы, но это не заменяет тест на реальном телефоне.
